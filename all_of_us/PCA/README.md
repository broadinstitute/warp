# PCA Analysis Pipeline

This directory contains `pca_only_no_labels`, a WDL workflow that performs Hardy-Weinberg equilibrium–normalized Principal Component Analysis (PCA) on genomic variant data (using [Hail](https://hail.is/)) for exploratory analysis of population structure **without** population labels.

## Documentation

Full documentation for this pipeline lives on the WARP documentation site:

**➡️ [pca_only_no_labels pipeline documentation](https://broadinstitute.github.io/warp/docs/All_of_Us/PCA_Analysis/pca_only_no_labels)**

The docs page covers the workflow's inputs, tasks and tools, outputs, runtime requirements, and usage notes.
