## Introduction to the RNA-SeQC2 Aggregation workflow

[`aggregate_rnaseqc2.wdl`](https://github.com/broadinstitute/warp/blob/develop/all_of_us/rna_seq/GTEx/aggregate_rnaseqc2.wdl) defines workflow `rnaseqc2_aggregate_workflow`, which combines per-sample RNA-SeQC2 outputs into cohort-level files.

The workflow accepts newline-delimited lists of input file paths, stages those files in a working directory, and runs `rnaseqc aggregate` to create cohort-level metrics and expression matrices. Insert-size histograms and additional RNA-SeQC2 command-line flags are optional.

## Inputs

### Input descriptions

| Input variable name | Description | Type |
| --- | --- | --- |
| `tpm_gcts_list` | Newline-delimited list of per-sample TPM GCT file paths. | File |
| `count_gcts_list` | Newline-delimited list of per-sample count GCT file paths. | File |
| `exon_count_gcts_list` | Newline-delimited list of per-sample exon-count GCT file paths. | File |
| `metrics_tsvs_list` | Newline-delimited list of per-sample metrics TSV file paths. | File |
| `prefix` | Prefix used for the aggregated output filenames. | String |
| `insertsize_hists_list` | Optional newline-delimited list of per-sample insert-size histogram file paths. | File? |
| `flags` | Optional additional command-line flags passed to `rnaseqc aggregate`. | String? |
| `memory` | Memory allocated to the aggregation task, in GB. | Int |
| `disk_space` | Disk space allocated to the aggregation task, in GB. | Int |
| `num_threads` | Number of CPUs allocated to the aggregation task. | Int |
| `num_preempt` | Number of preemptible retries for the aggregation task. | Int |

## Outputs

| Output variable name | Filename, if applicable | Output format and description |
| --- | --- | --- |
| `metrics` | `<prefix>.metrics.txt.gz` | Aggregated RNA-SeQC2 metrics. |
| `insert_size_hists` | `<prefix>.insert_size_hists.txt.gz` | Aggregated insert-size histograms, or an empty placeholder when no histogram list is supplied. |
| `tpm_gct` | `<prefix>.gene_tpm.*` | Cohort-level gene TPM matrix generated by `rnaseqc aggregate`. |
| `count_gct` | `<prefix>.gene_reads.*` | Cohort-level gene read-count matrix generated by `rnaseqc aggregate`. |
| `exon_count_gct` | `<prefix>.exon_reads.*` | Cohort-level exon read-count matrix generated by `rnaseqc aggregate`. |

## Workflow and WDL

- Workflow: `rnaseqc2_aggregate_workflow`
- Source WDL: [`aggregate_rnaseqc2.wdl`](https://github.com/broadinstitute/warp/blob/develop/all_of_us/rna_seq/GTEx/aggregate_rnaseqc2.wdl)

## Processing stages

1. **Stage input files:** downloads the TPM, count, exon-count, and metrics files listed in the required path-list inputs. If provided, it also downloads insert-size histogram files.
2. **Aggregate outputs:** runs `rnaseqc aggregate` on the staged files, passing the requested prefix and optional flags.
3. **Publish results:** returns the aggregated metrics, expression matrices, and insert-size histogram output.
